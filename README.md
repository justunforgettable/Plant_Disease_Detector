# Plant Disease Detection using CNN

This project uses a Convolutional Neural Network (CNN) to detect diseases in tomato leaves.

## Features

- Upload leaf image
- Disease prediction
- Confidence score
- Severity information
- Treatment suggestions
- Prevention methods

## Technologies Used

- Python
- TensorFlow
- Streamlit
- NumPy
- PIL
